# ASC-ODE

ASC-ODE is a C++20 library for solving ordinary differential equations. The
[project documentation](https://joelalfaroupc.github.io/ASC-ODE/) describes
its time-stepping methods and numerical experiments.

## Documentation publishing

The documentation is published on GitHub Pages. See the
[publishing guide](docs/publishing.md) for the classical `gh-pages` workflow
and the GitHub Actions workflow used by this repository.
