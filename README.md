# ASC-ODE

ASC-ODE is a C++20 library for solving ordinary differential equations. The
[project documentation](https://joelalfaroupc.github.io/ASC-ODE/) describes
its time-stepping methods and numerical experiments.

The [Euler and ODE experiments](https://joelalfaroupc.github.io/ASC-ODE/exercises-euler)
include plots and explanations of time-step accuracy, convergence, energy
and RC circuit stability.
